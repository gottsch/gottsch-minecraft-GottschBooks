Not everything is made at the crafting table. Each block below has its own recipes, and the book shows each the way
its block does.

## Smelting {#smelting}

```recipe minecraft:glass
Sand in a furnace makes glass. The time under the arrow is how long it takes.
```

```recipe minecraft:iron_ingot_from_blasting_raw_iron
A blast furnace smelts ores twice as fast, and nothing else.
```

## Cooking {#cooking}

```recipe minecraft:cooked_beef_from_smoking
A smoker cooks food twice as fast.
```

```recipe minecraft:cooked_beef_from_campfire_cooking
A campfire needs no fuel, but takes its time.
```

## Cutting Stone {#stonecutting}

```recipe minecraft:stone_bricks_from_stone_stonecutting
A stonecutter turns one block into one cut block, with nothing wasted.
```

## Smithing {#smithing}

```recipe minecraft:netherite_pickaxe_smithing
A template, a [diamond pickaxe](entry:tools#diamond) and a netherite ingot make a netherite pickaxe.
```

```recipe minecraft:coast_armor_trim_smithing_template_smithing_trim
A trim template decorates armour with the pattern it names, in the colour of the material.
```
