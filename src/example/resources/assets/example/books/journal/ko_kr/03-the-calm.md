# 고요

*넷째 날 밤.*

폭풍이 지나갔다. 바다는 잔잔하고 잿빛이며, 등불은 한 번에 붙었다. 내 앞의 등대지기가 그랬듯이, 이번 주 물때를 적어
두었다.

| 요일 | 만조 | 간조 |
|---|:---:|:---:|
| 월요일 | 새벽 전 | 오전 중 |
| 화요일 | 새벽 | 정오 |
| 수요일 | 오전 중 | 이른 오후 |
| 목요일 | 정오 | {dark_aqua}해 질 녘{} |

바다와 나 사이에 어떤 약속 같은 것이 생긴 듯하다. [문 앞에 왔던 그것](entry:02-the-visitor)은 다시 오지 않았다.
